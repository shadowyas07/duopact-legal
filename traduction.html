Les règles

  • Écris en lettres arabes, sur un ton familier, comme entre potes.
  • Les mots entre { } sont remplacés par l'application (un prénom, une durée…) : garde-les tels quels. Touche-les pour les insérer.
  • Les boutons et titres doivent rester courts.
  • Points : +10 par traduction, +2 par vote, +3 chaque fois qu'on vote pour ta traduction.
  • Les traductions hors sujet ou insultantes sont supprimées, avec les points.
